# COLOR MIX LAB (カラーミキシング・パズル)

パレットの12色の中から指定された色数を選び、調合（混色）してお題となる目標色（Target Color）に一致させる色彩感覚推理パズルゲームです。

## 🎮 主な機能・モード

- **🧪 フリー練習モード**: 目標色と調合結果のリアルタイムプレビュー、HSV一致率ゲージを見ながら直感的に学べるモード。
- **🏆 チャレンジモード**: 制限時間や問題数を設定し、調合結果が隠されたブラインド状態で連続挑戦するスコアアタック。
- **⚔️ オンライン対戦モード**: 6桁のルームIDを共有して、別端末や別タブ同士でリアルタイムに推理力を競うモード（クイックチャット付き）。

## 🎨 混色アルゴリズム
- **CMYK（減法混色）**: 絵の具を混ぜ合わせるような減法混色計算。
- **RGB（加法混色）**: 光の三原色を足し合わせるような加法混色計算。
